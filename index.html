Özel dosya kasanı kur

Dosyaların kendi özel GitHub deponda durur. Sunucu ya da ek yazılım gerekmez.

Bağlantı

Token nasıl alınır?
  1. Özel depo oluştur: github.com/new adresinde Private seç, Add a README file'ı işaretle.
  2. Token sayfasını aç: Token sayfası. Ad: dosya-kasasi, süre: 90 gün.
  3. Erişimi sınırla: Repository access → Only select repositories → depoyu seç. Permissions → Contents: Read and write.
  4. Kopyala: Generate token'a bas, github_pat_… değerini hemen kopyala. Sayfadan çıkınca bir daha gösterilmez.
  5. Yapıştır: Yukarıdaki forma gir. Başka cihazda bağlıysan oradaki Ayarlar → QR ile telefonu bağla yeterli.

Uygulama olarak yükle

iPhone/iPad: Safari'de Paylaş simgesine dokun, sonra Ana Ekrana Ekle'yi seç.

Uygulama bu cihaza yüklü.

Tarayıcı menüsündeki "Uygulamayı yükle" ya da "Ana ekrana ekle" seçeneğini kullanabilirsin.

Yükle

Dosyaları sayfaya sürükleyebilir ya da Ctrl+V ile yapıştırabilirsin. En fazla 100 MB, 25 MB üstü başarısız olabilir.

Uygulama PIN'i

4-8 rakam. Token bu PIN ile şifrelenip saklanır. PIN'i unutursan bağlantıyı sıfırlaman gerekir.

QR kodu okut

Telefonu QR ile bağla

Telefonda kurulum ekranındaki QR ile bağlan ile ya da kamerayla okut. QR token'ını içerir, sadece kendi telefonunla okut. 2 dakikada kapanır.
