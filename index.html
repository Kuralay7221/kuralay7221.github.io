▣Dosya Kasası

Özel dosya kasanı kur

Dosyaların kendi özel GitHub deponda durur. Kart, sunucu ya da ek yazılım gerekmez, kurulum yaklaşık 3 dakika sürer.

  1. Özel bir depo oluştur

    GitHub'da yeni depo sayfasını aç. Bir ad ver (örn. depo), görünürlüğü Private seç, Add a README file'ı işaretle ve Create repository'ye bas.

    Depo oluştur ↗

  2. Token sayfasını aç

    Token name alanına dosya-kasasi yaz. Expiration için 90 gün ya da özel bir tarih seç. Resource owner kendi hesabın olmalı.

    Token sayfası ↗

  3. Erişimi tek depoya sınırla

    Repository access bölümünde Only select repositories'i seç ve oluşturduğun depoyu işaretle. Sonra Permissions → Add permissions ile Contents'i ekle, erişimi Read and write yap. Başka izin verme.

  4. Token'ı kopyala

    Generate token'a bas. github_pat_… ile başlayan değeri hemen kopyala, sayfadan çıkınca bir daha gösterilmez.

  5. Buraya yapıştır ve bağlan

    Sağdaki forma kullanici/depo biçiminde depo adını ve token'ı gir. Depo herkese açıksa bağlanmayı reddeder.

Bağlantı

Token yalnızca bu tarayıcının localStorage'ında saklanır. Ortak bilgisayarda işin bitince bağlantıyı kes.
